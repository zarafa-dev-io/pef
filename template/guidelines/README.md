# Consignes de contenu (guidelines)

La couche **contenu** de vos Assets : ce qu'on écrit *dans* les sections — ton, vocabulaire, niveau de détail, exigences propres à votre organisation. Complémentaire de `templates/` (la **forme** : quelles sections) ; le front matter, lui, reste le contrat du framework (`schemas/`).

| Fichier | Portée |
|---|---|
| `redaction.md` | Consignes globales, tous Assets |
| `<suffixe>.md` (ex. `spec.md`, `bug.md`) | Consignes propres à un type — optionnel, créez selon vos besoins |

Les IA les chargent **systématiquement** avant toute rédaction (skill `pef-asset-authoring`) ; vos consignes priment sur leurs habitudes. **Ce répertoire vous appartient** : personnalisez librement, `update-framework` n'y touche jamais.
